AI sales agent, team inbox, CRM and commerce platform for WhatsApp,

START HERE
----------
1. Open Documentation/index.html in your browser.
   It explains requirements, installation, configuration and updates.

2. For a step-by-step walkthrough of every command, open
   Documentation/Sellora-AI-Installation-Guide.docx

3. Upload sellora-ai.zip to your server. It contains the application
   (folder "sellora-ai"). Do not upload this whole download.

REQUIREMENTS (short)
--------------------
- A VPS or dedicated server with root access (Ubuntu 22.04/24.04 recommended)
- 2 GB RAM minimum (4 GB recommended)
- Node.js 20+, PostgreSQL 14+, Redis 5+, Nginx
  (the included setup script installs all of them on Ubuntu)
- Ordinary cPanel shared hosting is NOT supported.
