Sellora AI

AI sales agent, team inbox, CRM and commerce platform for WhatsApp, website chat, Messenger and Instagram. Multi-tenant SaaS you host on your own server.

Version {{VERSION}} · Thank you for your purchase. This page explains how to install, configure and update Sellora AI. It works offline: open it in any browser.

1. Introduction

Sellora AI lets businesses sell through chat. An AI agent answers customers on WhatsApp and other channels, finds products, checks stock, quotes totals, takes orders and sends payment links, and hands the conversation to a person whenever needed. You run it as a SaaS: each business gets its own workspace, team, plan and data.

Dashboard of a workspace (demo data).

AI sales agentProduct search, stock, quotes, leads, orders and payment links through controlled tools. Every action is checked and logged.
Omnichannel inboxWhatsApp Cloud API, website chat widget, Messenger and Instagram in one realtime inbox with AI/human takeover.
CRMCustomers, leads, deals with drag-and-drop pipelines, tasks and notes.
CommerceProducts, categories, inventory with reservations, orders, invoices (PDF), payments and deliveries.
PaymentsStripe, PayPal, Razorpay, Paystack, SSLCOMMERZ, payment-link providers and manual methods such as bKash, Nagad, UPI, M-Pesa, bank transfer and cash on delivery.
Knowledge baseTeach the AI from PDF, Word, text, Markdown and web pages.
AutomationVisual workflows with triggers, conditions and actions, retries and run logs.
SaaS platformPlans and limits, plan payments, platform admin, editable home page, setup wizard.
SecurityWorkspace isolation, roles and permissions, 2FA, audit log, encrypted secrets, rate limits.

Technology

Next.js 16 and React (web), NestJS 11 with Prisma (API), PostgreSQL, Redis with BullMQ (background jobs) and Socket.IO (realtime). In production it runs with PM2 behind Nginx. Docker is not needed.

4. Install on a VPS (Ubuntu, recommended)

The setup script installs and configures everything: Node.js 22, PostgreSQL, Redis, Nginx, PM2, a firewall, brute-force protection, daily encrypted backups and a .env file with fresh secrets. Allow about 30 minutes.

  1. Point your domain to the server. At your domain registrar create an A record, for example app → your server IP. You can also start with the bare IP address and add a domain later.
  2. Upload the application. On your computer (PowerShell on Windows, Terminal on macOS/Linux): 
    scp sellora-ai.zip root@YOUR_SERVER_IP:/root/
  3. Unpack it on the server. Connect with ssh root@YOUR_SERVER_IP, then: 
    apt update && apt install -y unzip
mkdir -p /opt/sellora-ai/app
unzip /root/sellora-ai.zip -d /root/sellora-unzipped
cp -a /root/sellora-unzipped/sellora-ai/. /opt/sellora-ai/app/
  4. Prepare the server (replace the domain with yours, or with the server IP): 
    bash /opt/sellora-ai/app/deploy/scripts/setup-server.sh none app.yourshop.com sellora
    At the end the script prints your installer token and a backup passphrase. Save both in a password manager.
  5. Build and start the application as the sellora user: 
    sudo -iu sellora
cd /opt/sellora-ai/app && ./deploy.sh
    This installs packages, builds the API and web app, creates the database tables, starts the API, worker and web app with PM2 and checks that everything is healthy. The first run takes 5 to 10 minutes.
  6. Open the setup wizard at http://app.yourshop.com/install (see the next section).
  7. Turn on HTTPS (see section 8).
The Word guide in the Documentation folder walks through each of these steps with more detail, including how to connect with SSH from Windows.

5. The setup wizard

Open /install on your site. The wizard checks the server, tests the database, saves settings, creates the tables and creates your platform administrator account. When it finishes it locks itself, so nobody else can run it.

Where is the installer token?

The wizard asks for a token so that no stranger can take over a fresh installation. Find it on the server:

grep INSTALLER_TOKEN /opt/sellora-ai/.env

If INSTALLER_TOKEN is empty, the API generates one on start and writes it to storage/install-token.txt in the application folder and to the API log (pm2 logs sellora-api).

Without the wizard

You can create the administrator from the command line instead. This also locks the wizard:

cd /opt/sellora-ai/app/apps/api
npm run db:seed -- --admin you@example.com 'Your-Strong-Passw0rd'

7. Run on your computer

For testing or development on Windows, macOS or Linux. Install Node.js 22, PostgreSQL and Redis (on Windows, use Memurai or Redis in WSL), then:

unzip sellora-ai.zip && cd sellora-ai
cp .env.example .env        # set DATABASE_URL, REDIS_URL, JWT_SECRET, JWT_REFRESH_SECRET, ENCRYPTION_KEY
npm install
npm run db:deploy           # create the tables
npm run db:seed:demo        # optional: demo workspace "Acme Commerce"
npm run dev                 # web on :3000, API on :4000, worker

Open http://localhost:3000. Demo sign-in (only after seeding demo data): demo@sellora.test / SelloraDemo2026. Never load demo data on a live server you use for real customers.

8. Domain and HTTPS

  1. Make sure your domain points to the server (ping app.yourshop.com shows the server IP).
  2. Get a free certificate: 
    sudo certbot --nginx -d app.yourshop.com
  3. In /opt/sellora-ai/.env set: 
    APP_URL=https://app.yourshop.com
API_URL=https://app.yourshop.com
CORS_ORIGINS=https://app.yourshop.com
COOKIE_SECURE=true
TRUST_PROXY=true
  4. Apply it: cd /opt/sellora-ai/app && ./deploy.sh (the web app includes the address at build time).
The address in your browser must match APP_URL exactly. A different host, port or http/https causes sign-in loops or "Security check failed" errors.

9. First steps after install

Sign in with the administrator account. Platform administrators see Platform admin in the user menu.

  1. Email: set the SMTP_* values in .env and run ./deploy.sh. Without email, invitation links are shown on screen to share by hand, and password reset is not available.
  2. AI key for everyone (optional): set OPENAI_API_KEY in .env to give all workspaces AI without their own key. Leave it empty if each business should bring its own key.
  3. Plan prices: Platform admin → Plan payments. Set the monthly price of each plan, the currency and how businesses pay you (bKash, Nagad, bank transfer, or card through Stripe with STRIPE_SECRET_KEY). The home page pricing follows these prices.
  4. Home page: Platform admin → Edit home page. Change the brand name, texts, sections, FAQ and search-engine text.
  5. Create a workspace for yourself or invite your first business. Each workspace's dashboard shows a "Get ready to sell" checklist.

10. AI sales agent

The inbox: the AI answers, your team can take over at any time.

  1. Settings → AI: paste an API key (OpenAI or any OpenAI-compatible service), press Save, then Test connection. Keys are stored encrypted. A custom base URL is used only together with the workspace's own key.
  2. Products: add products with prices and stock. The AI only quotes prices and stock it finds in the catalog.
  3. AI → Knowledge base: upload delivery terms, return policy, FAQs, opening hours (PDF, Word, text, Markdown or a web address).
  4. AI → AI instructions: rules for every agent, for example "Never offer discounts."
  5. AI → Agents: set tone, language, escalation rules, working hours and which tools the agent may use. Test it in the Playground: it runs in test mode and creates nothing.

Orders are placed only after the customer confirms the summary. If the AI is unsure, over its plan limit or the provider fails, the conversation goes to your team automatically.

11. WhatsApp

Sellora AI uses Meta's official WhatsApp Cloud API. You need a Meta developer app and a WhatsApp Business account; Meta's approval can take a few days.

  1. At developers.facebook.com create an app, add WhatsApp and a phone number.
  2. Create a System User with whatsapp_business_messaging and whatsapp_business_management and generate a permanent token.
  3. In Sellora AI: WhatsApp → Accounts → Connect number. Enter the Phone number ID, WhatsApp Business Account ID, the token and the App secret (App settings → Basic).
  4. Copy the Callback URL and Verify token shown there into Meta → WhatsApp → Configuration → Webhook, and subscribe to messages.
  5. Press Test connection. Use Templates to message customers outside WhatsApp's 24-hour window.
No WhatsApp yet? Use Inbox → Test conversation to try the whole AI flow without sending anything.

12. Website chat, Messenger and Instagram

Website chat

Integrations → Website chat → Add website chat. Choose the AI agent, colours and greeting, then paste the one-line code before </body> on any website. Built-in guides cover WordPress, Shopify, Wix, Squarespace, Webflow and Google Tag Manager.

Messenger and Instagram

  1. In your Meta app add Messenger (and Instagram). Link your Instagram professional account to your Facebook Page.
  2. Generate a long-lived Page access token with pages_messaging (and instagram_manage_messages) and copy the App secret.
  3. Integrations → Messenger / Instagram → Connect, then paste the shown Callback URL and Verify token into the app's webhook settings.

Webhooks and API

Integrations → Webhooks sends signed events (orders, leads, messages, stock) to your other systems. Settings → API creates API keys; Integrations → Developer API shows ready-made examples. Full reference: docs/API.md.

13. Payments and plans

Orders with payment and delivery status.

Payments for each business

Each business adds its own payment methods under Integrations → Payments: Stripe, PayPal, Razorpay, Paystack, SSLCOMMERZ, any provider through a payment link, or manual methods (bKash, Nagad, UPI, M-Pesa, bank transfer, cash on delivery). Each method can be limited to countries and currencies. The AI sends payment links or instructions in the chat, and verified gateway webhooks mark orders as paid.

Plans for your SaaS

Plans (Free, Starter, Pro, Business, Enterprise) limit AI messages, WhatsApp messages, members, products and more. Prices are set in Platform admin → Plan payments; the limits are in packages/shared/src/plans.ts. Platform admins can also assign a plan to any workspace. Businesses can pay you without a gateway: they submit a bKash, Nagad or bank transfer ID and you approve it. With STRIPE_SECRET_KEY and STRIPE_WEBHOOK_SECRET they can also pay by card.

14. Configuration (.env)

All settings live in one file: /opt/sellora-ai/.env. After changing it, run ./deploy.sh. The most important values:

VariableMeaning
APP_URL, API_URL, CORS_ORIGINSYour public address, for example https://app.yourshop.com.
DATABASE_URL, REDIS_URLDatabase and Redis connections (set by the setup script).
JWT_SECRET, JWT_REFRESH_SECRETRandom secrets for sign-in sessions.
ENCRYPTION_KEYEncrypts stored tokens and AI keys. Back it up. Never change it on a running installation, or stored secrets become unreadable.
COOKIE_SECURE, TRUST_PROXYtrue with HTTPS behind Nginx.
OPENAI_API_KEY, AI_DEFAULT_MODELOptional platform AI key and default model.
SMTP_HOST, SMTP_USER, SMTP_PASSWORD, MAIL_FROMOutgoing email.
STORAGE_DRIVER and STORAGE_*local (default) or s3 for S3-compatible storage.
BACKUP_PASSPHRASEEncrypts database backups. Keep a copy outside the server.

Every variable is described in docs/ENVIRONMENT.md.

15. Updating to a new version

Your data, settings and uploads are kept. deploy.sh backs up the database before it changes anything.

# on your computer
scp sellora-ai.zip root@YOUR_SERVER_IP:/root/

# on the server
rm -rf /root/sellora-unzipped && unzip /root/sellora-ai.zip -d /root/sellora-unzipped
rsync -a --exclude ".env" --exclude "storage" --exclude "node_modules" --exclude ".next" \
  /root/sellora-unzipped/sellora-ai/ /opt/sellora-ai/app/
chown -R sellora:sellora /opt/sellora-ai/app
sudo -iu sellora bash -c 'cd /opt/sellora-ai/app && ./deploy.sh'

Read the changelog before upgrading. If you changed the source code, keep your changes in Git and merge the new version into it.

16. Backups

The database is backed up every night at 02:15 and before every deployment to /opt/sellora-ai/backups, encrypted with BACKUP_PASSPHRASE. Backups older than 14 days are deleted.

/opt/sellora-ai/app/deploy/scripts/backup-db.sh                    # back up now
pm2 stop sellora-api sellora-worker
/opt/sellora-ai/app/deploy/scripts/restore-db.sh /opt/sellora-ai/backups/FILE   # a .dump or .dump.enc file
pm2 start sellora-api sellora-worker

Also copy backups, /opt/sellora-ai/.env and /opt/sellora-ai/app/storage/uploads to another place regularly.

17. Troubleshooting

Start with these commands on the server:

pm2 status
curl -s localhost:4000/health/ready
pm2 logs sellora-api --lines 100
ProblemSolution
Site does not openCheck pm2 status (all three online) and systemctl status nginx. Open only ports 80 and 443 in the firewall; use the address without a port.
Signed out right away, or "Security check failed"APP_URL, API_URL and CORS_ORIGINS must match the address in the browser. COOKIE_SECURE=true only with HTTPS.
"Invalid environment configuration"The message lists the wrong values. ENCRYPTION_KEY must be 64 hex characters.
/health/ready shows database: down or redis: downCheck the service (systemctl status postgresql / redis-server) and the URL in .env.
WhatsApp messages do not arriveOpen WhatsApp → Webhooks. No events: webhook not subscribed or site not reachable over HTTPS. Rejected events: wrong App secret.
AI does not replyThe conversation shows why: no AI key, plan limit reached, agent off or outside working hours. Use Settings → AI → Test connection.
Inbox does not update liveNginx must forward /socket.io/ with WebSocket headers (included in deploy/nginx/sellora.conf).
Upload too largeRaise MAX_UPLOAD_MB and Nginx client_max_body_size together.

More answers: docs/TROUBLESHOOTING.md.

18. FAQ

Do I need Docker?

No. Sellora AI runs directly with Node.js, PM2 and Nginx.

Which AI providers work?

OpenAI and any service with an OpenAI-compatible API. The default model is gpt-4o-mini; you can change it per workspace and per agent.

Is the WhatsApp integration official?

Yes. It uses Meta's WhatsApp Cloud API. Unofficial WhatsApp Web automation is not used.

Can each business use its own AI key and WhatsApp number?

Yes. Keys, numbers and payment methods are set per workspace and stored encrypted.

Can I change the name, logo and home page?

Texts, sections and the brand name are editable in Platform admin → Edit home page. Logos are in apps/web/public/brand; rebuild with ./deploy.sh after replacing them.

Can I translate the interface?

The interface is in English. The AI replies in the customer's language when the agent's language is set to "Auto".
