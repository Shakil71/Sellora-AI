Sellora AI – AI Sales Agent, Inbox & CRM SaaS for WhatsApp

Sellora AI is a self-hosted, multi-tenant SaaS platform that turns chat conversations into sales. An AI sales agent answers customers on WhatsApp, your website chat, Facebook Messenger and Instagram: it finds products, checks stock, quotes totals, places orders after the customer confirms and sends payment links. Your team sees everything in a realtime inbox and can take over any conversation at any time.

Run it as your own SaaS business: every customer business gets its own workspace, team, plan limits, AI key, WhatsApp number and payment methods.

AI Sales Agent

  • Works with OpenAI and any OpenAI-compatible API (per workspace or one platform key)
  • Controlled tools: search products, check stock, quote totals, create leads, place orders, send payment options and payment links, hand over to a human
  • Every tool call is authorized, validated and logged; prices and stock always come from your catalog
  • Knowledge base (RAG) from PDF, Word, text, Markdown and web pages
  • Tone, language (auto-detect), working hours, escalation rules and fallback per agent
  • Playground test mode that never creates real orders or payments
  • Automatic handoff to your team when the AI is unsure, over quota or the provider fails

Omnichannel Inbox

  • Official WhatsApp Cloud API with signed webhooks, delivery receipts, templates and the 24-hour window
  • Embeddable website chat widget (one line of code for WordPress, Shopify, Wix, Webflow and any site)
  • Facebook Messenger and Instagram Direct
  • Realtime updates, AI/human takeover, assignments, internal notes and attachments

CRM & Commerce

  • Customers, leads, deals with drag-and-drop pipelines, tasks
  • Products, categories, inventory with reservations, low-stock alerts
  • Orders with status history, invoices (PDF), payments, refunds and deliveries
  • Product import from Shopify and WooCommerce store links, WooCommerce API, JSON/XML/CSV feeds, Excel, CSV, Word and PDF files

Payments

  • Per-business gateways: Stripe, PayPal, Razorpay, Paystack, SSLCOMMERZ and any payment-link provider
  • Manual methods: bKash, Nagad, UPI, M-Pesa, bank transfer, cash on delivery
  • Limit each method to countries and currencies; verified gateway webhooks mark orders paid

SaaS Platform

  • Plans with limits (AI messages, WhatsApp messages, members, products, workflows, storage)
  • Plan billing by card (Stripe) or without a gateway: bKash, Nagad or bank transfer with admin approval, renewals and grace period
  • Platform admin: workspaces, plan payments, queue health, failed jobs
  • Editable home page: brand, headline, features, steps, FAQ, testimonials, SEO text
  • Web setup wizard protected by an installer token

Automation, Analytics & Integrations

  • Visual workflow builder with triggers, conditions, actions, delays, retries and run logs
  • Dashboard and analytics for revenue, orders, leads, conversations and AI usage
  • REST API with scoped API keys and signed outgoing webhooks with retries and delivery log

Security

  • Strict workspace isolation, roles and ~55 granular permissions
  • HTTP-only cookie sessions with refresh rotation, CSRF protection, two-factor authentication
  • AES-256-GCM encryption for tokens and keys, Argon2id passwords, audit log, rate limits
  • SSRF protection for every outgoing request, encrypted database backups

Technology

  • Next.js 16, React, TypeScript, Tailwind CSS
  • NestJS 11, Prisma 6, PostgreSQL, Redis, BullMQ, Socket.IO
  • No Docker needed: PM2 + Nginx on any Ubuntu VPS, with a one-command server setup script, zero-downtime deploy script, health checks and daily backups
  • Unit and integration tests, light and dark theme, responsive design

Requirements

  • VPS or dedicated server with root access (Ubuntu 22.04/24.04 recommended), 2 GB RAM minimum
  • Node.js 20+, PostgreSQL 14+, Redis 5+ (installed automatically on Ubuntu)
  • A domain with HTTPS for WhatsApp, Messenger and Instagram
  • Your own AI key (OpenAI or compatible) and Meta developer app for WhatsApp
  • Not compatible with cPanel shared hosting

What You Get

  • HTML documentation and a step-by-step installation guide (VPS, cloud, cPanel/WHM, local)
  • Server setup, deployment, backup and restore scripts
  • Demo data seeder
